# local_grid_suite

Local Grid Suite is a small pair of command-line tools for benchmarking and reporting local LLM hardware telemetry.

## Tools

- `grid-benchmark` - runs streaming Ollama benchmarks and logs telemetry to SQLite
- `grid-report` - queries telemetry history and generates terminal/PDF reports

## Usage

- `./grid-benchmark --help`
- `./grid-report --help`
